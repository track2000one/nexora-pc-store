# NEXORA PC Store

React + Vite storefront with premium glass product cards.

## Local development
```bash
npm install
npm run dev
```

## Railway
This repository is configured for Railway using Docker + Caddy.

## Product Images
Product images are configured from Google Drive file IDs in `src/data.js`.
Each image must be shared as **Anyone with the link - Viewer** in Google Drive for public rendering.
